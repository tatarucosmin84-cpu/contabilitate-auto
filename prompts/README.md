# Prompturi de lucru

| Fișier | Când se folosește |
|---|---|
| `inchidere-perioada.md` | Închiderea lunii sau a trimestrului pentru o societate. În Claude Code se apelează cu `/inchidere-perioada <firma>, <luna/trimestrul> <an>`. Conținutul poate fi copiat și ca instrucțiuni într-un proiect claude.ai. |

Lecțiile învățate de regulă se țin în `lectii/lectii-invatate.md` (generale) și în `istoric/<CUI>.md` (pe firmă). Se gestionează cu `/lectii`, `învață: …`, `uită: …`.
